# 日常任务
<!-- last-modified -->

>游戏玩法

## 任务规则
游戏内共有5项任务，排除第一项和第二项固定外，每隔24小时对剩下三项任务刷新，从下列任务列表中抽取。玩家可通过完成任务给予的目标来获取指定数量的星星或者方块，每项任务会有进度显示，完成后任务会显示此项完成。

## 任务列表

> [!TIP]
> 此表格列出所有完整任务，提供参考

| 任务目标                                    | 奖励              |
|---------------------------------------|-------------------|
| **登录游戏（固定第一项）**                | **500 星星✨**     |
| **通关任意关卡1次（固定第二项）**          | **100 星星✨**     |
| **通关任意关卡3次**                     | **200 星星✨**     |
| **消耗200星星**                        | **200 星星✨**     |
| **在任意关卡中收集20颗钻石**              | **200 星星✨**     |
| **在任意关卡中收集6个皇冠**               | **200 星星✨**     |
| **在任意关卡中死亡10次**                 | **200 星星✨**     |
| **在任意关卡中复活5次**                  | **200 星星✨**     |
| **消耗15个方块**                       | **20 体力方块**     |

## 补充
- “日常任务”位于主菜单功能首位，也可以从[星星](/dlce/coins.md#star)界面和[体力方块](/dlce/coins.md#cube)购买界面跳转。
- 每项任务完成后任务项变灰静默。
